# G-Kentei-Quiz

`G-Kentei-Quiz` は、G検定の学習を支えるためのクイズ・模擬演習アプリです。問題演習、解説、反復学習を組み合わせることで、ただ暗記するのではなく、理解しながら学べる学習体験を作ることを目的としています。

## 状態

- 現在の位置づけ: active
- 目的: G検定の学習ループを回せるクイズアプリを作る
- 今後の方向性: 学習モード、模試モード、解説強化を段階的に整備する

## このリポジトリで目指すこと

- G検定の主要トピックを反復できる問題演習
- 学習内容を定着させるための解説と復習導線
- 模擬演習として使える一連の出題体験

## 次のタスク

1. MVP の学習ループを定義する
2. 学習モードと模試モードを分ける
3. 問題カテゴリと難易度の構造を整理する
